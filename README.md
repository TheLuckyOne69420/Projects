# Local Bites Restaurant Ordering System

A modular, multi-file Java console application designed for local restaurant order processing, menu browsing, dynamic cart accumulation, tax calculation, and receipt generation. Built using core Object-Oriented Programming (OOP) principles.

---

1. Open your IDE and create a new Java Project (or open the project folder).
2. Copy all eight .java files into the src directory.
3. Open Main.java.
4. Click Run or Debug (or press Shift + F10 in IntelliJ / F5 in VS Code).

# How to use the system
1. Browse Menu: Upon launch, the system automatically displays categorized foods and drinks with their corresponding IDs and prices.
2. Select Item: Enter the numeric ID of the item you wish to order.
3. Specify Quantity: Enter the quantity (must be a positive integer >= 1).
4. View Running Receipt: The application displays your current subtotal, 8% sales tax, and calculated total.
